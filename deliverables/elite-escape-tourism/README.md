# Elite Escape Tourism × DigitalBurj — UI/UX Transformation Deck

`elite-escape-tourism-uiux-deck.pptx` is a 12-slide, 16:9 (1920×1080) placeholder deck
illustrating a before/after UI/UX transformation for Elite Escape Tourism (a Dubai travel
agency), built for DigitalBurj using the design tokens and slide-by-slide brief supplied
for this request.

This deliverable is unrelated to the Loadbyton freight marketplace app in the rest of this
repository — it was generated and stored here because that's where this task was assigned.

All body copy is placeholder text in `[BRACKETS]`, per the brief — replace it with real
copy before presenting. Fonts are set to safe, portable substitutes (Arial for
Geist/Outfit, Cambria for Merriweather); swap in the real Geist/Outfit variable fonts in
PowerPoint/Keynote for final delivery.
