# Elite Escape Tourism × DigitalBurj — Transformation Pitch

This deliverable is unrelated to the Loadbyton freight marketplace app in the rest of this
repository — it was generated and stored here because that's where this task was assigned.

## What's here

- **`cinematic-experience.html`** — a self-contained, animated scrollytelling page (the
  source behind the published Claude artifact). Real navy/blue/cyan brand recreated from
  the client's actual logo, plus real research: eliteescapetourism.com is currently indexed
  serving unrelated Japanese resale listings via `/goods.php` and `/shop.php`, and a stray
  WordPress category — that's presented as a live "exhibit," not a hypothetical. Open the
  file directly in a browser; there are no external dependencies.
- **`elite-escape-reborn-deck.pptx`** — an 8-slide, 16:9 companion deck covering the same
  narrative (live evidence → real services → AI concierge vision → before/after rebuild →
  30-day target scoreboard → offer/pricing → contact). Slide-level fade transitions are
  baked into the OOXML for presentation mode. The orbit/"e" mark is redrawn as native
  PowerPoint shapes (gradient approximated via interpolated arc segments, since PowerPoint
  shapes don't support gradient strokes) so it stays crisp and editable at any size.

## Real data used

Company details, services, and the live compromise evidence were pulled from public search
results for `eliteescapetourism.com` (WebSearch / Firecrawl — this sandbox has no general
internet egress, so nothing was scraped by direct fetch). Contact info: Office 305, Damas
Dubai Tower, Rigga Al Buteen, Dubai, UAE · +971 55 575 3133 · inquiries@eliteescapetourism.com.
KPI figures on the "30-day target" slide/section are explicitly labeled as targets, not
already-delivered results.

## Brand notes

The logo mark (navy-to-cyan gradient orbit ring with a small dart, "ELITE ESCAPE TOURISM
LLC" wordmark) was recreated by eye from the logo image supplied in chat — this sandbox
can't download files from a pasted link, only inline-attached images it can visually read.
Swap in the client's original vector/PNG logo file for final production if pixel-perfect
fidelity matters more than the redrawn version.

Fonts are safe, portable system-font stacks (no external font files were available to
embed, and Google Fonts can't be fetched from this sandbox either) — swap in the brand's
real typeface if one is specified later.
